# Cognex Benchmark Results

These benchmarks measure the performance of Cognex under its current storage engine design:

- WAL-backed durability
- Append-only ValueLog
- Offset-based indexing
- Batched fsync() strategy

---

## PUT Benchmark

**Workload:**  
Inserted **1,000,000 key–value pairs**

| Metric | Value |
|--------|--------|
| Operations | 1,000,000 |
| Total Time | 39.501 sec |
| Throughput | **25,315.8 ops/sec** |

---

## GET Benchmark

**Workload:**

|--------|--------|

| Throughput | **1,639,340 ops/sec** |

##  Mixed Benchmark (50% PUT / 50% GET)

**Workload:**  
Alternating PUT and GET operations

| Metric | Value |
|--------|--------|
| Operations | 1,000,000 |
| Total Time | 19.174 sec |
| Throughput | **52,154 ops/sec** |

---

##  Observations

- `PUT latency` is influenced by:

- WAL writes
- ValueLog appends
- Batched fsync()

- `GET operations` remain extremely fast due to:

- Offset-based index lookup

- Direct pread() ValueLog reads

- `Log-structured writes` minimize random disk IO.

- `fsync batching` significantly improves write throughput by reducing sync amplification.
